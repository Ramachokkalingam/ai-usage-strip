# Changelog

## 1.0.0 (2026-11-01)

First release.

- Usage strip above the chat box on Claude, ChatGPT, Gemini, Perplexity, Grok and DeepSeek.
- Plan limit meter: live 5-hour and weekly usage on Claude, estimates from sent messages elsewhere.
- Reset timer, context fill estimate and messages sent today.
- Details panel with every limit window, context breakdown and a 7-day chart.
- Toolbar popup with all sites and a percentage badge on the toolbar icon.
- Settings for plans, limits, window types, context size, placement, size and colors.
- Detects "you've reached your limit" notices.
- Works in Chromium browsers and Firefox 121+ from one codebase.
- Privacy policy and store listing package.
